# 在线 ERP 预处理

平台保持 1000 Hz，分段为刺激前 100 ms 至刺激后 500 ms（右端不包含，600 个点）。
事件使用采集时定位的软件标签，不经过 EDF 或 pop_biosig。

处理顺序：连续整体 1–10 Hz FIR → 坏导球面插值 → 重参考（全通道平均参考）→ 分段 →
刺激前 100 ms 基线校正 → 整试次振幅/方差剔除 → Target、Standard 平均及差异波。
不做多个频段分析，不删除通道，不运行 ICA/ICLabel。重参考采用全通道平均参考方法，不是 MATLAB 的 REST。
700 ms 是相邻刺激间隔，不是分段长度；600 ms 分段对应当前 MATLAB 的 −0.1～0.5 s。

## 坏导插值

每次记录收集前10秒有效的1–10 Hz连续滤波数据，忽略最初2秒滤波瞬态，沿用 detect_bad_electrodes.m：
500点窗口、50%重叠；超过200 µV的窗口比例>0.7则判坏（第27～30通道阈值150 µV）；
窗口极差<20 µV的比例>0.95也判坏。低振幅的正常通道也可能触发这个判据，需结合真实数据核对。
用MNE球面样条插值保留通道位置；这是与EEGLAB相同类型的方法，不保证数值逐点一致。
有效供体少于4个时明确停止ERP分析，不强行插值；原始数据仍保存。
插值矩阵和坏导列表在本次初始化后固定，随后用于所有连续ERP输入。

## 初始化与等待

- 已删除 ICA 分解、ICLabel 分类、眼电投影和1–100 Hz校准副本，不再做主动眼电校正。
- 前10秒有效滤波数据用于坏导检测，不是眼电模型校准；初始化前的连续数据缓存后统一回放处理。
- 首次坏导初始化约需10秒有效数据，加上1.65秒滤波等待和少量计算时间。
- 停止时不足10秒但至少有3秒有效滤波数据时，使用已有数据初始化；不足3秒明确提示预处理不可用。
- 原始数据先保存。若坏导初始化尚未完成，完成后再导出ERP结果。
- 眼电等残留伪迹仅通过后续试次质控筛查，不等于所有眼电均被去除。

## 时间和单位

整体 FIR 在 1000 Hz 下为 3301 个系数，在线需等待 1650 个未来样本。
输出对回原始采样时间，软件标签不移动。连同后窗，试次约在刺激后 2.15 秒可完整提取。
停止采集时不使用虚构的未来样本补齐窗口，末尾未齐全试次会标记为未纳入。

采集输入和连续预处理使用 V；分段后转为 µV。
坏导插值和重参考使用全部采集通道，ERP质量检查仅使用 Fz、FC1、FC2、Cz、Pz。
基线校正后，这五个通道中任一通道最大绝对幅值 >100 µV，或这五个通道的全试次方差
>1000 µV²（N−1分母）时整试次剔除。四个显示选项共享同一套有效试次，切换选项不改变计数。
质量检查在通道合并前进行，避免多个通道平均后抵消伪迹。

ERP界面固定为四个选项：Fz + FC1 + FC2 的逐时刻算术平均、Cz、Pz、Fz，默认 Pz。
缺少所需通道时明确提示，不自动用其他通道替代。其他通道不直接参与ERP质量检查，但仍参与坏导插值和重参考。

## 保存结果

原有 EDF、CSV、事件 JSON 和标注 Excel 仍保存原始数据与软件事件。
另外保存同名 `.erp.npz` 和 `.erp.json`：

- NPZ：五个关键通道的有效试次、平均波形、差异波，以及四个选项的组合平均波形；数值单位为 µV。
  `channel_names`对应五个ERP通道，`preprocessing_channel_names`对应完整预处理输入通道。保存FIR系数，不再保存ICA投影或ICLabel概率。
  另保存 `bad_channel_interpolation` 球面插值矩阵；JSON保存坏导名称和检测比例。
- JSON：处理参数、坏导检测与插值、有效/未纳入数量、每个试次最大幅值与方差、最大幅值所在通道及剔除原因；明确标记 `ica_enabled=false`。
- 无有效试次时保留空结果和原因，不生成假的 ERP 波形。

依赖见 `requirements-erp.txt`，已安装到指定 VR 环境。重启平台使代码生效。
整体FIR不声称与pop_eegfiltnew系数完全一致，MNE球面样条插值与EEGLAB不保证逐点一致。
当前验证禁止调用ICA或导入ICLabel/ONNX，检查正常与注入坏导的实际平台模拟、分段、重参考、基线、绘图与保存。

逐条网络数据和硬件触发成功日志默认关闭。需要诊断时设置环境变量 `EEG_VR_DEBUG=1`；错误、连接状态和保存结果继续保留。
