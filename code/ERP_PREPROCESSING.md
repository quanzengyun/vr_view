# 在线 ERP 预处理

平台保持 1000 Hz，分段为刺激前 200 ms 至刺激后 800 ms（右端不包含，1000 个点）。
事件使用采集时定位的软件标签，不经过 EDF 或 pop_biosig。

处理顺序：单次整体 1–30 Hz FIR → ICA/ICLabel 去眼电 → 全通道平均参考 → 分段 →
刺激前 200 ms 基线校正 → 整试次振幅/方差剔除 → Target、Standard 平均及差异波。
不做多个频段分析，不删除或插值坏导。重参考当前为平均参考，不是 MATLAB 的 REST。

## 眼电校准

- 每次开始记录后，收集前 60 秒，在后台拟合一次 extended Infomax ICA。
- ICLabel 使用校准副本的 1–100 Hz 数据、标准 10–20 坐标及平均参考；原始采集和保存数据不变。
- 使用与 MATLAB 脚本相同的眼电判定：第三类概率 ≥0.8，最多两个成分。其他类别不删除。
- 未达到阈值时不会强制删除成分。模型错误时也不会把未清理数据冒充清理结果。
- 模型就绪前，完整试次暂存，随后统一使用同一模型处理，避免混合不同处理条件。
- 停止时若不足 60 秒但已有 30 秒，会使用已有数据拟合；不足 30 秒则明确记录校准不足。
- 原始数据先保存。若停止时仍在拟合，界面等待模型完成后保存 ERP 结果，再允许开始下一次记录。

## 时间和单位

整体 FIR 在 1000 Hz 下为 3301 个系数，在线需等待 1650 个未来样本。
输出对回原始采样时间，软件标签不移动。连同后窗，试次约在刺激后 2.45 秒可完整提取。
停止采集时不使用虚构的未来样本补齐窗口，末尾未齐全试次会标记为未纳入。

采集输入和眼电投影使用 V；分段清理后转为 µV。
ICA和平均参考使用所有采集通道，ERP质量检查仅使用 Fz、FC1、FC2、Cz、Pz。
基线校正后，这五个通道中任一通道最大绝对幅值 >100 µV，或这五个通道的全试次方差
>1000 µV²（N−1分母）时整试次剔除。四个显示选项共享同一套有效试次，切换选项不改变计数。
质量检查在通道合并前进行，避免多个通道平均后抵消伪迹。

ERP界面固定为四个选项：Fz + FC1 + FC2 的逐时刻算术平均、Cz、Pz、Fz，默认 Pz。
缺少所需通道时明确提示，不自动用其他通道替代。其他通道不直接参与ERP质量检查，但仍参与ICA和平均参考。

## 保存结果

原有 EDF、CSV、事件 JSON 和标注 Excel 仍保存原始数据与软件事件。
另外保存同名 `.erp.npz` 和 `.erp.json`：

- NPZ：五个关键通道的有效试次、平均波形、差异波，以及四个选项的组合平均波形；数值单位为 µV。
  `channel_names`对应五个ERP通道，`ica_channel_names`对应完整ICA输入通道。眼电模型就绪时也保存完整投影、偏置、ICLabel 概率和 FIR 系数。
- JSON：处理参数、成分选择、有效/未纳入数量、每个试次最大幅值与方差、最大幅值所在通道及剔除原因。
- 无有效试次时保留空结果和原因，不生成假的 ERP 波形。

依赖见 `requirements-erp.txt`，已安装到指定 VR 环境。重启平台使代码生效。
Python ICA 拟合与 MATLAB runica 的数值结果不保证逐位相同；整体 FIR 也不声称与 pop_eegfiltnew 系数完全一致。
验证分别检查实际 ICLabel、已知眼电模拟信号、FIR 时间补偿，以及 MATLAB 基线/试次剔除/平均计算。
